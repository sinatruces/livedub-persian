# livedub-persian

ترجمه صدای فایل‌های صوتی/تصویری خودتون (مثلاً انگلیسی) به صدای فارسی با Gemini گوگل.
ورودی: فایل‌ها یا پوشه‌ها (mp3، wav، m4a، mp4، mkv و …) — خروجی: فایل WAV فارسی به‌همراه متن ترجمه.

دو روش ترجمه داره:

- **کیفیت بالا (پیش‌فرض):** گفتار با `gemini-3.8-flash` به متن تبدیل میشه، کل متن یکجا و با دستورالعمل
  «فارسی طبیعی و روان برای گویندگی» ترجمه میشه، و بعد `gemini-3.8-flash-tts` با صدایی که خودتون انتخاب
  می‌کنید اون رو می‌خونه. سریع‌تر از طول فایله.
- **ترجمه زنده:** مدل `gemini-3.5-live-translate-preview`، یک مترجم همزمان. جمله‌به‌جمله و بدون دیدن ادامه‌ی
  متن ترجمه می‌کنه و صدای خودش رو داره، برای همین نتیجه مصنوعی‌تره و هم‌اندازه طول فایل زمان می‌بره.

> اسکریپت روی سیستم خودتون اجرا میشه، ولی ترجمه روی سرور گوگل انجام میشه؛ پس اینترنت و کلید API لازمه، هزینه داره و صدای فایل‌ها برای گوگل فرستاده میشه.

## ساده‌ترین راه: صفحه وب روی کامپیوتر خودتون

1. **Python 3.11 یا جدیدتر** رو از https://www.python.org/downloads/ نصب کنید (در ویندوز تیک «Add python.exe to PATH» رو بزنید).
2. **ffmpeg** رو نصب کنید:
   - ویندوز: `winget install Gyan.FFmpeg`
   - مک: `brew install ffmpeg`
   - لینوکس: `sudo apt install ffmpeg`
3. این پروژه رو دانلود و از حالت فشرده خارج کنید.
4. اجرا:
   - ویندوز: روی **`start.bat`** دوبار کلیک کنید.
   - مک/لینوکس: در ترمینال داخل پوشه پروژه بزنید `sh start.sh`
5. مرورگر خودش صفحه **http://localhost:8000** رو باز می‌کنه. کلید Gemini API رو یک بار وارد کنید (از https://aistudio.google.com/apikey).
6. فایل رو انتخاب کنید، صدا رو انتخاب کنید (با «شنیدن نمونه صدا» قبلش امتحانش کنید)، لحن رو «روایی و روان» یا «محاوره‌ای» بذارید و «شروع ترجمه» رو بزنید.

بار اول نصب بسته‌ها چند دقیقه طول می‌کشه؛ دفعه‌های بعد سریعه. تا وقتی کار تموم نشده، پنجره ترمینال رو نبندید.
در صفحه می‌تونید پیشرفت کار رو ببینید، ترجمه رو همون‌جا گوش بدید و فایل WAV (و متن ترجمه) رو دانلود کنید.
فایل‌ها و نتیجه‌ها در پوشه `web_data` و کلید در فایل `.env` کنار پروژه ذخیره میشن.

## خط فرمان (برای پردازش دسته‌ای)

بعد از اینکه یک بار `start.bat` یا `start.sh` اجرا شد، محیط پایتون در پوشه `.venv` آماده‌ست:

```bash
# ویندوز:      .venv\Scripts\activate
# مک/لینوکس:  source .venv/bin/activate
```

کلید رو تنظیم کنید:

```bash
# مک/لینوکس
export GEMINI_API_KEY="کلید-شما"
# ویندوز (PowerShell)
$env:GEMINI_API_KEY="کلید-شما"
```

```bash
# یک فایل → output/lecture.fa.wav
python -m livedub lecture.mp3

# یک پوشه کامل (زیرپوشه‌ها هم خونده میشن و همون ساختار در خروجی ساخته میشه)
python -m livedub my_audios/ -o persian/

# صدای مرد و لحن محاوره‌ای
python -m livedub lecture.mp3 --voice Charon --style casual

# روش ترجمه زنده (Live Translate)، با ذخیره متن
python -m livedub lecture.mp3 --mode live --save-text
```

خروجی کنار هر `lecture.fa.wav` شامل `lecture.fa.txt` (متن ترجمه) و `lecture.source.txt` (متن اصلی) هم هست؛
اگه صدا ایراد داشت، از روی متن می‌تونید ببینید مشکل از ترجمه‌ست یا از خوندن.

اول با یک فایل کوتاه (۲-۳ دقیقه) امتحان کنید و کیفیت فارسی رو بسنجید.
فایل‌هایی که خروجی‌شون از قبل وجود داره رد میشن، پس اگه وسط کار متوقف شد، همون دستور رو دوباره اجرا کنید.

| گزینه | توضیح | پیش‌فرض |
|---|---|---|
| `-o` | پوشه خروجی | `output` |
| `-l` | زبان مقصد (کد BCP-47) | `fa` |
| `--mode` | `quality` (کیفیت بالا) یا `live` (ترجمه زنده) | `quality` |
| `--voice` | صدای Gemini: Kore، Sulafat، Aoede، Despina (زن) — Charon، Achird، Algieba، Puck (مرد) | `Kore` |
| `--style` | `formal` (روایی و روان) یا `casual` (محاوره‌ای) | `formal` |
| `-j` | تعداد درخواست‌ها (یا جلسه‌های زنده) به‌طور همزمان | `4` / `1` |
| `--retries` | تعداد تلاش دوباره در صورت خطا | `2` |
| `--overwrite` | دوباره‌سازی خروجی‌های موجود | خاموش |
| `--text-model` / `--tts-model` | مدل‌های روش کیفیت بالا | `gemini-3.8-flash` / `gemini-3.8-flash-tts` |
| `--model` | مدل روش زنده | `gemini-3.5-live-translate-preview` |
| `--segment-minutes`، `--pace`، `--save-text` | فقط برای روش زنده | |

## چطور کار می‌کنه

در هر دو روش، اول ffmpeg صدای فایل رو به PCM شانزده‌بیتی، مونو، 16kHz تبدیل می‌کنه و فایل‌های بلند در نزدیک‌ترین سکوت به تکه‌های حداکثر ۵ دقیقه‌ای بریده میشن.

**کیفیت بالا:**
1. هر تکه برای `gemini-3.8-flash` فرستاده میشه و متن گفتار (بدون مکث‌ها و «اِ…»ها) برمی‌گرده.
2. متن کامل، به ترتیب و همراه با چند پاراگراف قبلی برای یکدستی اصطلاحات، ترجمه میشه. دستورالعمل ترجمه
   می‌خواد معنی منتقل بشه نه کلمه، نیم‌فاصله و علائم فارسی درست باشه، اعداد و اختصارها همون‌طور که خونده
   میشن نوشته بشن، و هر جا تلفظ ممکنه اشتباه بشه کسره‌ی اضافه گذاشته بشه.
3. متن فارسی در تکه‌های چندجمله‌ای به `gemini-3.8-flash-tts` داده میشه تا با صدای انتخابی و لحن «گوینده‌ی
   حرفه‌ای با لهجه‌ی تهرانی» خونده بشه، و تکه‌ها با مکث کوتاه به هم وصل میشن.

**ترجمه زنده:** هر تکه با سرعت زمان واقعی برای مدل Live Translate فرستاده میشه و صدای ترجمه‌شده‌ی خود مدل ذخیره میشه.

## سهمیه‌ی رایگان (free tier)

اگه برای پروژه‌ی کلیدتون پرداخت فعال نباشه، گوگل تعداد درخواست‌ها رو محدود می‌کنه؛ برای `gemini-3.8-flash`
حدود ۲۰ درخواست در روز، و مدل صدا هم سهمیه‌ی روزانه‌ی جدای خودش رو داره.

- هر یک ساعت صدا تقریباً ۲ درخواست تبدیل گفتار به متن و ۱ تا ۲ درخواست ترجمه لازم داره، و ساخت صدا
  حدوداً یک درخواست برای هر ۲ دقیقه صدای فارسی.
- هر بار «شنیدن نمونه صدا» برای یک صدا/لحن تازه هم یک درخواست از سهمیه‌ی مدل صدا مصرف می‌کنه.
- اگه سهمیه وسط کار تموم بشه، صفحه می‌گه چقدر باید صبر کنید. بعدش دکمه‌ی **«ادامه»** رو بزنید (یا در خط
  فرمان همون دستور رو دوباره اجرا کنید)؛ قسمت‌هایی که انجام شده دوباره درخواست نمی‌فرستن.
- برای استفاده‌ی جدی، در [Google AI Studio](https://aistudio.google.com/) برای پروژه‌ی کلیدتون پرداخت (billing)
  رو فعال کنید. طبق قیمت‌هایی که سایت‌های دیگه منتشر کردن، هزینه حدود یک دلار برای هر ساعت صداست؛ قیمت
  دقیق رو از صفحه‌ی قیمت‌گذاری گوگل ببینید.

## محدودیت‌ها

- **سرعت روش زنده:** هر تکه تقریباً به اندازه طول خودش زمان می‌بره.
- **هماهنگی با ویدیو:** طول جمله‌های فارسی با اصل فرق داره، پس خروجی خودبه‌خود با تصویر هماهنگ نیست.
- **مدل preview:** ممکنه اسم یا رفتارش عوض بشه؛ در اون صورت با `--model` مدل جدید رو بدید.
- **مرز تکه‌ها:** جمله‌ای که دقیقاً روی مرز دو تکه باشه ممکنه کمی ناقص ترجمه بشه؛ برش‌ها در سکوت انجام میشن تا این کمتر پیش بیاد.

## تست‌ها

تست‌ها با یک جلسه جعلی Gemini اجرا میشن و به کلید API نیاز ندارن:

```bash
pip install -r requirements-dev.txt
python -m pytest
```
