# livedub-persian

ترجمه صدای فایل‌های صوتی/تصویری خودتون (مثلاً انگلیسی) به صدای فارسی با مدل **Gemini Live Translate** گوگل.
ورودی: فایل‌ها یا پوشه‌ها (mp3، wav، m4a، mp4، mkv و …) — خروجی: فایل WAV فارسی.

> اسکریپت روی سیستم خودتون اجرا میشه، ولی ترجمه روی سرور گوگل انجام میشه؛ پس اینترنت و کلید API لازمه، هزینه داره و صدای فایل‌ها برای گوگل فرستاده میشه.

## پیش‌نیازها

- Python نسخه 3.11 یا جدیدتر
- ffmpeg (برای خوندن هر نوع فایل صوتی/ویدیویی)
  - ویندوز: `winget install ffmpeg`
  - مک: `brew install ffmpeg`
  - لینوکس: `sudo apt install ffmpeg`
- کلید Gemini API از https://aistudio.google.com/apikey

## نصب

```bash
python -m venv .venv
# ویندوز:      .venv\Scripts\activate
# مک/لینوکس:  source .venv/bin/activate
pip install -r requirements.txt
```

تنظیم کلید:

```bash
# مک/لینوکس
export GEMINI_API_KEY="کلید-شما"
# ویندوز (PowerShell)
$env:GEMINI_API_KEY="کلید-شما"
```

## استفاده

```bash
# یک فایل → output/lecture.fa.wav
python -m livedub lecture.mp3

# یک پوشه کامل (زیرپوشه‌ها هم خونده میشن و همون ساختار در خروجی ساخته میشه)
python -m livedub my_audios/ -o persian/

# متن ترجمه‌شده و متن اصلی رو هم ذخیره کن (lecture.fa.txt و lecture.source.txt)
python -m livedub lecture.mp3 --save-text

# فایل‌های بلند رو سریع‌تر کن: سه تکه به‌طور همزمان
python -m livedub lecture.mp3 -j 3
```

اول با یک فایل کوتاه (۲-۳ دقیقه) امتحان کنید و کیفیت فارسی رو بسنجید.
فایل‌هایی که خروجی‌شون از قبل وجود داره رد میشن، پس اگه وسط کار متوقف شد، همون دستور رو دوباره اجرا کنید.

| گزینه | توضیح | پیش‌فرض |
|---|---|---|
| `-o` | پوشه خروجی | `output` |
| `-l` | زبان مقصد (کد BCP-47) | `fa` |
| `-j` | تعداد تکه‌هایی که همزمان ترجمه میشن | `1` |
| `--segment-minutes` | حداکثر طول هر تکه (هر تکه یک جلسه جدا با API) | `5` |
| `--pace` | سرعت ارسال صدا نسبت به زمان واقعی (بیشتر از 1 آزمایشیه) | `1.0` |
| `--retries` | تعداد تلاش دوباره برای هر تکه در صورت خطا | `2` |
| `--save-text` | ذخیره متن ترجمه و متن اصلی | خاموش |
| `--overwrite` | دوباره‌سازی خروجی‌های موجود | خاموش |
| `--model` | مدل Live API | `gemini-3.5-live-translate-preview` |

## چطور کار می‌کنه

1. ffmpeg صدای فایل رو به PCM شانزده‌بیتی، مونو، 16kHz تبدیل می‌کنه (همون فرمتی که API می‌خواد).
2. فایل‌های بلند در نزدیک‌ترین سکوت به تکه‌های حداکثر ۵ دقیقه‌ای بریده میشن، چون هر جلسه Live API محدودیت زمانی (~۱۵ دقیقه) داره.
3. هر تکه با سرعت زمان واقعی، در بسته‌های ۱۰۰ میلی‌ثانیه‌ای، برای مدل فرستاده میشه و صدای فارسی (24kHz) دریافت میشه.
4. تکه‌ها به هم چسبونده میشن و در یک فایل WAV ذخیره میشن.

## محدودیت‌ها

- **سرعت:** مدل برای ترجمه زنده ساخته شده، پس هر تکه تقریباً به اندازه طول خودش زمان می‌بره. با `-j` چند تکه همزمان پردازش میشن (تا جایی که سهمیه API اجازه بده).
- **هماهنگی با ویدیو:** طول جمله‌های فارسی با اصل فرق داره، پس خروجی خودبه‌خود با تصویر هماهنگ نیست.
- **مدل preview:** ممکنه اسم یا رفتارش عوض بشه؛ در اون صورت با `--model` مدل جدید رو بدید.
- **مرز تکه‌ها:** جمله‌ای که دقیقاً روی مرز دو تکه باشه ممکنه کمی ناقص ترجمه بشه؛ برش‌ها در سکوت انجام میشن تا این کمتر پیش بیاد.
