ffmpeg نصب نیست

برای خوندن فایل‌ها لازمه. نصبش کنید، پنجره ترمینال رو ببندید و دوباره اجرا کنید:

ویندوز: winget install Gyan.FFmpeg · مک: brew install ffmpeg · لینوکس: sudo apt install ffmpeg

کلید Gemini API

فقط یک بار لازمه؛ روی همین کامپیوتر در فایل .env ذخیره میشه. کلید رو از aistudio.google.com/apikey بگیرید.
